# GeoTrust static deployment

The website lives at /F459/ on GitHub Pages. Each directory contains a real index.html.

## Visual assets
visual-story.css and visual-story.js implement the signal journey. Reduced-motion settings disable automatic motion; the controls remain usable. site-*.css files are generated page bundles; source CSS is retained for maintenance.

## Search and sharing
All pages declare their canonical URL, favicon and Open Graph image. sitemap.xml lists the 11 public pages. robots.txt is supplied in this project directory. Crawlers normally read /robots.txt at the domain root; the owner of enhancement-social.org must include the project sitemap there if a root robots policy is desired. This repository cannot change another site's root robots.txt or /favicon.ico. Pages explicitly request /F459/favicon.ico.

No Lighthouse scores are asserted for this revision. The earlier audit scores were supplied by the project owner.
