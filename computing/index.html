01 / INTUITION

如何把數學模型變成連續的訊號？

一段訊號檔案是一連串按固定時間間隔排列的樣本。系統要同時維持多顆衛星的時間、碼與相位，最後才把它們加在一起。

02 / MECHANISM

把中間的步驟連起來。

  1. 設定與星曆

    準備時間、軌跡與衛星軌道資料。

  2. 通道狀態

    依衛星幾何更新延遲、頻率與相位。

  3. 樣本合成

    逐通道產生複數樣本，保持區塊之間的連續性。

  4. 加總與輸出

    合成多通道後量化寫檔；檢查飽和與資料格式。

取樣率決定每秒要計算多少樣本，訊號頻寬決定需要保留多少頻率資訊。加速不能只看執行緒數：記憶體搬移、同步、寫檔與相位連續性都會限制整體效能。

探索更多：術語與進階模型x[n] = Σₖ xₖ[n]

xₖ[n] 是第 k 顆衛星在第 n 個取樣時刻的複數樣本。加總前須共享一致的時間基準，輸出量化時需留意動態範圍；不能把各通道各自算對就視為整個系統正確。

03 / IN GEOTRUST

這一步，在 GeoTrust 裡做什麼？

CPU 狀態 → H2D → CUDA 樣本平行 → D2H → 輸出

GeoTrust 技術文件描述 CUDA 核心已實作：一個 GPU 執行緒對應一個複數取樣，逐一累加有效通道。CPU 更新幾何與通道狀態，GPU 產生 I/Q，輸出端量化並以有界佇列處理背壓。每毫秒仍有主機／裝置傳輸，效能不能只由 kernel 時間推算。

探索更多：從設定到可查證的輸出

輸入：模擬時間、位置或路徑、星曆。中間狀態：每星延遲、碼相位、載波與資料索引。輸出：I/Q 與 JSON。查證時固定版本及輸入，再比較編碼向量、頻譜與接收機結果。
