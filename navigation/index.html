01 / INTUITION

手機如何把時間變成位置？

衛星不會直接告訴手機「你在這裡」。它廣播時間與軌道資料，接收機把多顆衛星的距離線索組合成位置。

02 / MECHANISM

把中間的步驟連起來。

  1. 星曆

    從軌道參數算出衛星在訊號發射時的位置。

  2. 傳播時間

    訊號到達要花時間；乘上光速可換成距離。

  3. 鐘差

    手機時鐘不夠準，因此量到的是含時鐘誤差的偽距。

  4. 幾何解算

    一般三維單一時間系統需解位置三軸與鐘差四個未知數。

接收機先用測距碼對齊訊號，得到碼相位，再結合電文時間資訊建立偽距。僅靠一次碼的對齊，還不能知道完整的傳播時間。多顆衛星的幾何分布也會影響誤差如何放大。

探索更多：術語與進階模型ρ = r + c(δtᵣ − δtₛ) + I + T + ε

ρ 是偽距、r 是幾何距離、c 是光速；δt 是時鐘偏差，I、T 是大氣延遲，ε 是其他誤差。四顆衛星是常見的最低條件，不是精度保證。

03 / IN GEOTRUST

這一步，在 GeoTrust 裡做什麼？

RINEX → 衛星狀態 → 傳播時間 → 通道延遲

GeoTrust 先由星曆算出衛星位置、解析式速度與鐘差，再由設定的位置或路徑求各星發射時間。地球自轉與選用的電離層修正影響偽距；完整修正偽距的變化率進一步連到都卜勒與碼率。

探索更多：從設定到可查證的輸出

輸入：模擬時間、位置或路徑、星曆。中間狀態：每星延遲、碼相位、載波與資料索引。輸出：I/Q 與 JSON。查證時固定版本及輸入，再比較編碼向量、頻譜與接收機結果。
