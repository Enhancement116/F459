跟著一次測試，看介面能做什麼

從選地點到重播測試，一次測試的每一步都在同一個畫面上完成。各功能的詳細說明與畫面整理中。

  1. 01選定地點與時間在地圖上指定待測設備以為自己所在的位置，以及模擬的日期與時刻。內容整理中
  2. 02選擇衛星系統選擇 GPS、北斗或兩者一起，並查看當下上空看得到的衛星。內容整理中
  3. 03設定測試情境設定要模擬的欺騙或干擾與參數，例如訊號強度、位置偏移與時間跳變。內容整理中
  4. 04規劃移動路線在地圖上點選起點與終點，選直線或沿真實道路，系統自動產生軌跡。內容整理中
  5. 05開始測試一鍵開始，即時查看訊號輸出與待測設備的反應。內容整理中
  6. 06儲存與重播儲存這次測試的設定與訊號，日後原封不動重播。內容整理中
