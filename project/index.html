01 / INTUITION

我們在模擬什麼？

衛星廣播軌道與時間，接收機由訊號推算位置。GeoTrust 從模型出發，產生 GPS L1 C/A 與北斗 B1I 複數基頻 I/Q，供教學、演算法開發與重播比較。

  1. 星曆衛星的軌道與時鐘模型
  2. 傳播把位置變成時間差
  3. 編碼資料 × 測距碼
  4. 合成每個時刻產生 I/Q
  5. 驗證讓獨立接收機讀回

02 / MECHANISM

一條時間一致的訊號管線

  1. 輸入RINEX、UTC、位置或路徑
  2. 模型軌道、鐘差、傳播與通道
  3. 輸出I/Q 檔案、JSON 或 UHD 串流

各衛星保有獨立的發射時間與導航資料；所有通道共用取樣時間軸。這讓路徑改變能一致地影響碼相位、載波與都卜勒。

探索更多：軟體設定摘要

文件列出的通道上限為 16，預設生成區塊為 1 ms。最低取樣率設定：GPS 2.6 Msps、北斗 5.2 Msps、混合 20.8 Msps。這些是平台設定，不是所有接收機的通用最低需求。

目前做到哪裡？研究邊界

依 2026-10-30 專案技術文件：CUDA 核心已實作；北斗聚焦 MEO／IGSO 的 B1I-D1，尚未支援 GEO／D2。GPS 與北斗子幀 4–5 仍為最小內容。GPS 專屬電離層係數、對流層與多路徑模型尚未完整納入。正式 GPU benchmark 尚待完成。
