01 / INTUITION

一段電波如何同時帶著資料與時間？

先分清三件事：資料說明衛星的狀態，測距碼提供辨認與對時的線索，載波負責把它們送進無線頻段。

02 / MECHANISM

把中間的步驟連起來。

  1. 導航電文

    裝入軌道、時間與健康等資訊；它是訊息內容。

  2. 編碼與擴頻

    錯誤更正碼保護資料；PRN 測距碼提供相關辨識，兩者目的不同。

  3. 調變與載波

    以波的相位等變化承載符號；BPSK 以兩種相位表示正負符號。

  4. I/Q 取樣

    以同相與正交兩個分量描述複數基頻，供數位處理。

擴頻把較慢的資料符號與較快的碼片序列結合。接收機產生已知碼的副本，調整時間偏移並比較相關程度；對齊時會出現峰值。真正接收還要處理都卜勒、雜訊與積分時間，不是只把波形看起來做得相像。

探索更多：術語與進階模型z(t) = I(t) + jQ(t)

I 與 Q 是同一訊號的兩個正交分量，不是兩個獨立的衛星。複數訊號的大小與角度描述振幅與相位；加入隨時間變化的相位可表示頻率偏移。

03 / IN GEOTRUST

這一步，在 GeoTrust 裡做什麼？

導航資料 → 同位／BCH → PRN／NH → 複數載波

GPS 與北斗分別建立導航資料與測距碼。B1I-D1 使用 BCH 與 NH20，GPS L1 C/A 使用導航字同位檢查。每顆衛星依自己的發射時間選擇位元與碼索引，再把碼、資料、振幅與載波相乘；多通道在同一個取樣時刻相加。

探索更多：從設定到可查證的輸出

輸入：模擬時間、位置或路徑、星曆。中間狀態：每星延遲、碼相位、載波與資料索引。輸出：I/Q 與 JSON。查證時固定版本及輸入，再比較編碼向量、頻譜與接收機結果。
